# kaly42
This repository contains a fully functional QMK/Vial Firmware for the Kaly42, in order to user please follow the instructions on the QMK Docs and Vial Software.
They way I use them are by clonning this repo inside the kaly/kaly42 directory, change to the vial branch and then compiling the files to create the bin file then I use qmk toolbox to flash my keyboard and that's it.

I will upload the bin file to this repo in case you need it.

Enjoy it!
